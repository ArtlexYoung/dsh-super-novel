# 评测说明

目前只完成小规模技术与写作验证，不能据此宣称质量提升或成本下降。

## 0.1.1 真实模型技术补验

2026-10-08，在 macOS 上通过实际安装包的 Host 服务和 Harness 模型适配器，使用合成作品完成 11 次真实调用，无自动重试。前 7 次使用较高推理强度，后 4 次为较低推理强度的独立补验；每次输出上限为 8192 tokens。具体模型与调用配置、原始文本只保存在本地忽略目录。

| 项目 | 结果 |
| --- | --- |
| 章纲、首章、选段润色 | 生成与采纳流程完成；首章 466 个非空白字符，要求 3 段却生成 4 段；润色区外逐字不变 |
| 高推理强度的事实提取与审校 | 3 次耗尽输出预算，事实提取失败、审校显示未知，依赖事实的下一章跳过 |
| 短文本事实与下一章补验 | 7 条事实引用位置有效；采纳后下一章 185 个非空白字符、2 段，满足该样本要求 |
| 完整返回的植入问题审校 | 引用位置正确，但状态写成非法值；插件拒绝结果并显示未知 |
| 局部修订 | 程序限定范围外逐字不变，但新内容沿用伤腕矛盾；不能算作有效修复 |
| 明确审校状态后再测 | 已补齐提示中的状态定义和回归检查；真实复验仍耗尽输出预算，没有正文，审校未通过 |
| 保存、重复请求与卸载重开 | 候选与正式正文分离，查询和重复操作不产生新调用；原稿保留 |

服务报告总用量为 64,432 tokens，包含失败调用；没有账单，费用未知。7 次以正常完成结束，4 次达到输出上限。较低推理强度也没有保证审校完成；本轮不继续增加调用或挑选成功结果。

这是技术补验和单个执行者的文本审阅，没有普通助手配对、多人盲评、长篇质量或跨平台验证。合成稿的采纳只用于验证存储，不代表作者接受文学质量。真实模型审校可靠性仍未通过。
