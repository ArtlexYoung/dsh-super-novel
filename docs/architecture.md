# 当前架构

当前 `0.0.2` 只有预设提示词、启用服务和状态侧栏。作品存储、事实回填和独立审校模块尚未实现。

## 模块

| 位置 | 职责 |
| --- | --- |
| `cordis.patch.yml` | 向 profile 插入插件服务，不覆盖宿主预设配置 |
| `src/index.ts` | 注册 Host 服务，通过 Remote 提供状态查询和启用操作 |
| `src/host/preset-install.ts` | 查找用户预设根，检查归属、版本、文件和锁，安装固定预设 |
| `src/preset/index.ts` | 在 Agent 作用域添加小说写作提示词 |
| `src/client/index.tsx` | 注册中英文侧栏，显示状态、启用按钮和错误 |
| `presets/dsh-super-novel/` | 提供预设名称和 Agent 插件组合 |

## 启用流程

1. profile 加载 bundle，注册 Host 服务和客户端侧栏。
2. 打开侧栏，通过 Remote 查询状态，不写文件、不调用模型。
3. 用户点击启用后，安装器检查目标目录，取得排他锁并写入预设及归属记录。
4. 宿主发现预设，用户在会话中选择 `Super Novel · 小说生成`。
5. 写作提示词加入该 Agent；模型、权限、工具和会话仍由宿主管理。

预设 ID 为 `dsh-super-novel`，由目录名确定。安装不改变默认模式，也不替换其他预设 roots。已有版本或文件不符时显示冲突，不自动覆盖。

## 构建与边界

构建生成 Host、Client 和 Typert/Remote 文件，安装包直接携带这些产物。客户端使用宿主服务，不另建模型运行时。

插件目前没有作品数据库或正文保存服务。提示词中的连续性检查、摘要和修改范围要求属于模型指导，不等于程序已经实现了事实回填、独立审校或修订验收。

历史技术验证主要覆盖 macOS Web；Desktop、Windows/Linux、热卸载和完整磁盘故障矩阵尚未验证。恢复限制见[使用说明](usage.md)。
