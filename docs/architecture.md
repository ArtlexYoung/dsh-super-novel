# 当前架构

当前 `0.1.6` 提供写作预设、作品存储、正文与规划资料、生成候选、事实/摘要候选、文风授权、导入导出、独立审校、有限修订、作者采纳、历史和冲突恢复，同时适配 DSH `0.1` 与 `0.2` 的宿主接口。工作台默认显示文档内容，AI 助手独立展示生成设置与候选；资料可直接新建并生成，或从保存正文整理。

## 启用流程

1. profile 加载 bundle，注册 Host 服务和客户端侧栏。
2. 打开侧栏，通过 Remote 查询状态，不写文件、不调用模型。
3. `0.1` 宿主在用户点击启用后检查目标目录，取得排他锁并写入预设及归属记录；`0.2` 宿主在插件加载时直接注册预设。
4. 宿主发现预设，用户在会话中选择 `Super Novel · 小说生成`。
5. 写作提示词加入该 Agent；模型、权限、工具和会话仍由宿主管理。

预设 ID 为 `dsh-super-novel`。旧宿主由目录名确定，新宿主由注册定义指定。两种方式都不改变默认模式。旧安装器不替换 roots，文件不符时不覆盖；新注册方式不写用户预设文件，重复 ID 或注册失败会明确报错，卸载时释放注册。

## 构建与边界

构建生成 Host、Client 和 Typert/Remote 文件，安装包直接携带这些产物。RPC codec 同时提供旧版 `schema` 与新版 `create()`，两者使用同一严格 Zod schema。客户端使用宿主服务，不另建模型运行时。

界面复用宿主公共 Button、Input、Tag 和图标。选择框保留原生键盘行为，外观使用相同主题 token。WebUI 与 Desktop 共用客户端。实际 pane 小于 760px 时以正文为主，底部五个入口打开目录、参考或管理；宽面板保留左侧目录。工具面板独立滚动，隐藏内容不卸载编辑器，返回时恢复选区、滚动和焦点。目录分类和筛选只改变列表，资料查看独立读取已保存内容；显式编辑资料前先提交草稿检查点。事实、授权、审校和保存位置从「更多」进入。

作品身份和章节身份使用稳定 UUID。标题只作展示，正文保存为 Markdown。索引包含格式版本、作品 revision 和各章 revision/hash。Host 从会话 header 获取 workspace，并读取该 workspace 的保存位置偏好。显式切换使用现有绝对目录，保留原库；会话工作目录和权限不变。只读策略阻止写入，workspace-write 限制实际根目录，远程 FS 被拒绝。

资料是带可选 kind 的书内 Markdown 文档，复用正文版本、提案与恢复协议。旧记录无 kind 时视为正文；章纲与场景可关联正文 UUID。作者勾选来源后，Host 读取同书文档并捕获 kind、版本、哈希和内容，不接受跨书、空文档或外部未登记改动。普通资料生成可选择保存正文；正文起草不通过此入口读取其他正文，仍使用资料与事实服务。提示区分保存正文与未来规划，普通资料采纳不更新事实或文风授权记录。来源变化使旧候选过期。

新建资料与生成候选是两个显式操作。浏览器保留创建请求和生成请求的独立操作身份；创建后生成失败时保留空资料，重试复用身份，不重复创建。资料页面复用同一个候选组件，生成、停止、对照和采纳在原页完成；手动模板与编辑继续保留。

保存先写完整恢复记录，再替换正文和索引，最后发布完成记录。失败保留旧稿与候选；新实例读取未完成状态，作者显式恢复。恢复只接受已记录的旧/新文件，第三种内容触发冲突。同书写入有跨进程锁，重复操作返回原结果。只读查询不创建文件，也不会恢复写入。

浏览器草稿使用 IndexedDB，兼容读取旧 localStorage，迁移成功才删除旧副本。Host 草稿按实际根目录、作品、章节与编辑分支隔离，含单调序号、基线和内容哈希。检查点不可变，写入使用文件 fsync、替换与目录同步，重复重发幂等。只明确处理相同检查点，历史保留；正式保存和草稿互相独立。恢复先预览，不能静默覆盖另一窗口的输入。正式保存不依赖浏览器数据或聊天记录。外部编辑器不参与插件锁，多文件保存不是跨文件原子事务。

Windows 跳过 Node 不支持的目录 fsync，文件写入仍执行 fsync；不承诺断电后的目录项持久性。文件替换遇到 EACCES/EBUSY/EPERM 时最多重试八次，每次重查当前正文和路径，发现冲突立即停止。其他平台和错误不会重试，不删除原文件作为回退。策略有模拟回归，Windows/Linux 实机仍未验证。

历史直接读取已完成保存记录，分页返回最多 100 项，不另建历史写事务。旧稿恢复与冲突处理产生新 revision，重复操作复用原结果。冲突稿不可变，实际保存仍检查当前磁盘哈希。中断后出现第三种正文时，作者可核对两稿并确认正文；原提交记录先归档，再替换待恢复记录，随后完成普通保存。没有该确认时不会覆盖第三种正文。

生成任务绑定 workspace、作品、章节、基线版本/哈希、授权选区和作者资料快照。模型只返回替换文本，选区外内容由程序原样拼接。候选状态与正文分离；采纳复用正文保存日志，完成记录用于识别中断后的重复采纳。查询不调用模型或自动恢复写入。

生成通过宿主 LLM 服务使用当前会话所选路由，没有工具、父聊天记录、额外文件读取或客户端 provider 请求。任务脱离浏览器请求运行，插件卸载、显式停止或超时会取消。只保留已收到的有效文本；没有明确完成、空输出和截断均不能采纳。缺失用量保持未知，不估算成实际账单。

事实提取无工具、无聊天历史；返回 JSON 经 schema 和引用位置检查后保存为独立候选。作者采纳复用普通文档保存日志，完成 receipt 用于幂等；正文失败恢复期间不使用混合状态。已采纳事实存为 kind=facts 的书内文档，关联来源正文 UUID、revision/hash，拥有历史。前章上下文过滤读者/人物知情范围，绑定事实文件和来源哈希；缺回填、过期或预算超限不能生成依赖事实的候选。没有语义蕴含自动证明，作者须审阅事实含义。

`domain/reviews.ts` 定义机械检查、审校结构与引用验证，`host/review-store.ts` 持久化绑定文本哈希/资料快照的只读审校。通过结论要求所有维度完成、无问题且依据有效。问题修订复用候选服务，以原问题引用为授权范围，选区外逐字保留；每条候选链最多两轮。正文或资料变化使原审校过期。

schemaVersion 1 的旧作品无需迁移，缺少 kind 的旧章节仍是正文。无新字段的旧候选和审校保持原格式与快照；未知高版本拒绝写入。卸载取消宿主任务并等待候选、事实提取和审校结束，保留候选前缀和 workspace 数据；热卸载、锁释放和重装读回已有 Host 回归，实际 Desktop 热卸载仍需验收。

实际验证覆盖 macOS `0.1.5-rc.2` Web 固定响应整链与重启，以及已安装 DSH NEXT `2.0.17-next`（宿主 `0.2.0-rc.2`）的窄栏、完整写作与重启。未使用版本豁免。其他符合依赖范围的版本尚未逐个运行；新布局的 Safari、Windows/Linux、真实质量和完整磁盘故障矩阵仍待补验。范围见[评测说明](evaluation.md)，恢复限制见[使用说明](usage.md)。

完整备份由 BookFiles 的每书快照屏障协调所有托管写者，冻结期间复制有界文件并检查外部修改，释放屏障后流式 tar/gzip。清单逐文件记录字节与 SHA-256，发布前完整回读核验。恢复再次核验已预览清单哈希，在临时新根写入并发布，不覆盖现有作品。备份查询不创建目录；只读/工作区权限在 RPC 校验。自动备份在写作请求后延时触发，执行时重新检查会话权限和根身份。

作品索引支持 strict schemaVersion 1/2；v1 不允许 v2 元数据。显式迁移先完整备份，然后复用 pending/receipt 保存协议，仅改索引。标签、别名、状态、多章/资料引用和选区来源均绑定稳定 ID。检索以 Markdown 为权威，派生小缓存可重建；每次查询读取实际 hash，预算/外部修改显示不完整，查询可取消且不落盘。归档/回收只改索引，所有生成入口校验可用状态。
